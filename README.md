# Polynomial Interpolation

These are my Jupyter notebooks from the CSE330 Numerical Methods course at BRAC University. I did them in 2022, in my B.Sc. in Computer Science and Engineering.

## What is inside

| Notebook | Topic |
|---|---|
| `01_floating_point_representation.ipynb` | How a computer stores real numbers, and rounding errors |
| `02_polynomial_interpolation.ipynb` | Fitting a polynomial through data points |
| `03_lagrange_interpolation.ipynb` | Lagrange interpolation |
| `04_hermite_and_newton_divided_difference.ipynb` | Hermite interpolation and Newton's divided difference |

The notebooks are templates from the course, with explanations and empty parts marked `# YOUR CODE HERE`. My code is in those parts.

## How to run

Step 1: Install Python 3 with NumPy and Matplotlib.

Step 2: Open a notebook in Jupyter or Google Colab and run the cells.
